# 📖 Overview

**Nxt-Watch** is a full-stack AI-powered movie discovery and streaming platform built with React, Node.js, Express, PostgreSQL, pgvector, Redis, and modern AI technologies.

Unlike a traditional OTT clone, Nxt-Watch adds an intelligent layer for:

- 🔎 Semantic movie search
- 🎯 Personalized recommendations
- 🤖 AI-powered movie assistant
- 🧠 Agentic AI and tool calling
- 📋 Natural-language Watch Later automation
- 👑 Admin-only movie management
- 🔐 Secure JWT authentication
- ❤️ Likes, dislikes, comments and watch history
- 🌐 External movie and video integrations

🔎 Semantic Search

Nxt-Watch uses Gemini embeddings + PostgreSQL pgvector for semantic movie search.

User Query
    │
    ▼
Gemini Embedding Model
    │
    ▼
Query Vector
    │
    ▼
PostgreSQL + pgvector
    │
    ▼
Vector Similarity Search
    │
    ▼
Relevant Movies

Instead of depending only on exact keywords, semantic search retrieves movies based on the meaning of the query.

Example
"movies about astronauts exploring unknown planets"

can retrieve semantically related movies even when the exact wording does not appear in the movie metadata.
